## Как читать этот документ

Секции независимы, если не указано иное. Внутри секции блоки идут по порядку.

- **DoD** — критерий готовности, проверяемый командой, а не мнением.
- **Риск** — что может сломаться.
- **Блокирован** — чем, если чем-то.

Правило на всю работу: **после каждого блока полный прогон**
(`pytest tests/ -q`, 5 477 тестов, ~41 мин) и чистое рабочее дерево.
Блок не закрыт, пока прогон не зелёный.
